# Projects Directory

You can place your project repositories, build outputs, or project assets in this folder.
The website's `js/projects-data.js` is already pre-configured to link with these directories.

### Example project directories:
- `projects/cloudscale-analytics/`
- `projects/lumina-craft-commerce/`
- `projects/devpulse-api-stream/`
- `projects/synccraft-collab/`

When you want to showcase a new project:
1. Put any screenshots or mockups into `assets/images/`
2. Open `js/projects-data.js` and add an entry with your title, description, tags, and links
3. It will automatically appear in your portfolio with filter support and the interactive detail modal!
